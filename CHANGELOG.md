# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-24

### Added
- Public release of Habit Tracker 2026
- Habit creation, tagging, scheduling, editing, and deletion
- Daily completion tracking with streak calculations
- Weekly statistics and 30-day completion history
- Cookie consent handling and settings page
- Packaging metadata for installation via pip

### Changed
- Finalized public project metadata for GitHub and PyPI release readiness
- Standardized release versioning to 1.0.0

### Notes
- This app is intended for local/single-user use and stores data in SQLite.
- For private deployments, set a strong `SECRET_KEY` environment variable.
